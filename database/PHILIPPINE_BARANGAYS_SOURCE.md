# Philippine barangay reference data

`philippine_barangays.json` contains 42,010 barangays and their parent city or municipality, province (when applicable), region, and PSGC code.

- Dataset snapshot: 2026-10-12
- Data release: [PSA Philippine Standard Geographic Code](https://psa.gov.ph/classification/psgc), Q3 2026
- Packaged hierarchy snapshot: [barangay-data-repository](https://github.com/bendlikeabamboo/barangay-data-repository/tree/main/2026-10-12)
- PSA data is available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the repository's packaging code is MIT licensed.

This is geographic reference data only. It does not mean the store serves every barangay. Owners must set a delivery fee and activate each area the store actually serves.
